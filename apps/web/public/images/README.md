# Site photography

Drop the founder-supplied photographs here using these exact filenames. Each is
referenced by an `ImageSlot`, which renders the brand gradient underneath — so a
missing file degrades to a labelled placeholder rather than a broken image.

| File                     | Used on           | Subject                                                       |
| ------------------------ | ----------------- | ------------------------------------------------------------- |
| `care-nurse-smiling.jpg` | `/` mission split | nurse laughing with a child holding a teddy                   |
| `care-teddy-oxygen.jpg`  | `/data`           | teddy bear in a hospital bed wearing an oxygen mask           |
| `care-thermometer.jpg`   | `/services`       | clinician taking a child's temperature, child holding a teddy |
| `care-resting.jpg`       | reserved          | child asleep in a hospital bed with a teddy                   |
| `founder-portrait.jpg`   | `/` and `/about`  | the founder's own photograph                                  |
| `library-screenshot.png` | `/knowledge`      | a real PedsCC Library page-level search result                |

Licensing: every photograph must be genuinely free-licensed or owned. None may
be captioned or positioned to imply it depicts TowardPCC's own unit, staff or
patients (see `docs/superpowers/specs/2026-07-27-site-redesign-design.md` §7).
